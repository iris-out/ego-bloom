# R 렌더 작업 보고

이 흐름을 맡은 에이전트가 마지막 점검 직전에 사용량 한도로 멈춰 보고서를 남기지 못했다. 아래는 메인 세션이 변경 내용을 기준선과 비교해 읽고 정리한 것이다. 코드는 모두 남아 있고 테스트, lint, 빌드, 측정으로 확인했다.

## 바꾼 것

### 그림자

- 본 화면 배치는 그림자를 던지지 않는다(`Instances` 의 `castShadow` 가 항상 false). 대신 `WorldScene.ShadowCasters` 가 그림자 절두체 근처 파트만 shape 별 `InstancedMesh` 에 담아 그림자 패스 동안만 보이게 한다. 그림자 draw call 은 shape 수(12 안쪽) 를 넘지 않는다.
- caster 목록은 `cityTiles.buildCasterIndex` 가 파트를 96 단위 격자에 넣어 만들고, `selectCasterCells` 가 절두체와 겹치는 칸만 고른다. 초점이 40 단위 안에서 움직이는 동안은 다시 채우지 않는다.
- 색인 만들기는 파트 16만 개를 한 번 훑어 50~80ms 가 들므로 `requestIdleCallback` 에서 한다. 첫 화면은 조감이라 caster 가 꺼져 있다.
- `SunLight` 가 그림자 절두체(중심, 반폭, far, 광원 방향) 를 ref 에 적고 `ShadowCasters` 가 그것을 읽는다.
- 움직이는 탈것과 항공기는 예전처럼 매 프레임 그림자를 던진다.

### draw call

- 공항 상자는 정점 색 geometry 한 장으로 굽고, 나머지 시설(게이트 제트, 연료 탱크, 레이더 돔, 헬리패드) 은 `StaticBatch` 로 묶었다. 공항 두 곳이 draw 180개에서 스무 개 안쪽이 됐다.
- AI 항공기도 정적 조각을 묶고 프로펠러와 로터만 남겼다. 스스로 움직이는 가지는 `cityTiles.snapshotPoses` 와 `markMoved` 가 몇 프레임 지켜본 뒤 자동으로 표시한다.
- picking 상자 재질을 `visible = false` 로 두었다. three 의 raycast 는 재질 가시성을 보지 않아 건물 클릭은 그대로 된다.
- 낮에는 빛 웅덩이 재질을 통째로 끈다. 불투명도 0 으로 두면 1만여 개가 계속 그려진다.
- 하늘을 불투명 물체 가운데 마지막에 그린다(`renderOrder` 999). 도시에 가려질 화소는 깊이 검사에서 버려진다. 하늘 셰이더는 정점에서 z 를 far 평면 바로 앞에 고정하고 로그 깊이를 쓰지 않아 늘 도시 뒤에 선다.

### CPU

- `WorldScene` 을 `React.memo` 로 감싸고 `City` 의 picking 콜백과 성능 보고 콜백을 ref 로 고정했다. 부모가 다시 렌더해도 도시 트리가 재조정되지 않는다.
- 장면 루트의 `matrixAutoUpdate` 를 끄고 정적 도시 노드를 `freezeStatic` 으로 굳혔다. 루트가 매 프레임 자기 행렬을 새로 만들면 모든 자식이 강제로 다시 계산된다.
- `Instances`, `SurfaceMesh`, `CityTiles` 를 memo 로 감쌌다.

### 셰이더

- production 빌드에서 `gl.debug.checkShaderErrors` 를 끈다. link 마다 로그를 동기로 읽으면 첫 사격과 1인칭 전환에서 수십 ms 씩 멈춘다.
- `ShaderPrewarm` 이 도시가 뜬 뒤 한가할 때 나중에 쓸 프로그램을 미리 만든다. 조명 조합(점광원, 스폿, 둘 다), 실내 전 기종, 총 전 무기, 폭발, 예광, 룸미러의 톤매핑 없는 키까지 덮는다. 떼어 둔 group 에 잠깐 마운트해 재질을 모으고 `dispose` 를 막아 프로그램이 지워지지 않게 붙든다.
- 작업은 `requestIdleCallback` 조각으로 나눠 입력을 막지 않는다. 메인 세션이 나중에 단계를 나눠, 탈것을 고른 뒤 카운트다운에는 조명 조합만, 조종 중에는 아무것도 하지 않게 했다.

### 해상도

- `AdaptiveResolution` 이 1초 지수 이동 평균으로 프레임 시간을 보고 22ms 를 계속 넘으면 dpr 을 0.85배씩 낮춘다(품질 등급 dpr 의 0.6배가 바닥). 12ms 아래로 여유가 생기거나 화면 주사율에 붙어 있으면 한 단씩 되돌린다. 2초에 한 번보다 자주 바꾸지 않는다.

## 확인

- 기준선 대비 draw call 은 도보 정지에서 507 에서 240 으로, 비행 1인칭에서 522 에서 215 로 줄었다. 자세한 숫자는 `03-results.md` 에 있다.
- 단위 테스트, lint, 빌드, Playwright 는 메인 세션이 돌렸다. 작업 전부터 있던 `WorldScene.jsx` 의 lint 오류 세 개도 이 흐름에서 사라졌다.

## 남은 문제

- 밤낮을 바꾸는 순간 가로등과 실내등이 생겼다 사라져 조명 개수가 바뀐다. 그때 한 번은 셰이더가 다시 만들어진다. 미리 컴파일이 이 조합까지 덮지 못했다.
- 그림자 caster 를 다시 채우는 경계(초점 30 단위 이동) 에서 그림자가 한 번에 바뀌는 것이 눈에 띄는지는 화면으로 확인하지 못했다.
